- App launches with framework present.
- App still launches when runtime resolver deliberately returns no hook class.
- Effect category browser opens.
- `Extensions & Scripts` appears exactly once directly below `Move & Transform`.
- Selecting the entry presents the panel.
- Closing and reopening the panel does not duplicate entries or proxies.
- Scrolling, rotation, background/foreground, project reopen, and export remain functional.
- Apple sign-in and normal account flows behave exactly as the baseline app.

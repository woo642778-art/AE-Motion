# v2.0.2 Native UI Integration Design

## Scope

This release changes presentation and entry-point placement only. It does not change render engines, preset data, Add Effects metadata, BCC aliases, or Alight Motion private project data.

## Placement architecture

Every tool receives a `ToolPlacement` classification. Contextual editing tools may be opened from the project editor toolbar menu while Extensions & Scripts remains a complete fallback directory. Global resources and diagnostics remain hub-first.

## Visual system

`AEMotionTheme` owns semantic backgrounds, surfaces, typography colors, accent colors, margins, corner radii, form controls, table views, scroll views, text views and empty states. Existing controllers reuse the component rather than creating independent visual styles.

## Host integration

The runtime resolver uses allowlisted `ProjectEditVC` names. It appends one menu item without replacing host buttons. When no visible navigation bar exists, it uses a compact safe-area overlay fallback. Hook failure leaves the host unchanged.

The Effect Picker hook fills the root and scrollable backgrounds, collapses the hidden recommendation strip, and supplies a clear empty state when a collection is genuinely empty.

## Safety constraints

- No timeline or project database writes.
- No removal of original host controls.
- No duplicate contextual button installation.
- No broad runtime class enumeration.
- No effect metadata changes.

# AE Motion Extensions v1.9.2 Stabilization Design

## Scope

v1.9.2 completes the previously agreed stabilization release without starting the v2.0 preset-system work. It addresses six areas: reliable Depth Map preview and diagnostics, BCC effect search metadata, first-frame Extensions category installation, removal of the recommendation carousel above Add Effects, cancellable single-flight rendering, and temporary-file/memory safeguards.

## Architecture

### Render safety layer

A new host-side `RenderJobCoordinator` owns one render task per tool controller. It enforces single-flight execution, exposes cancellation through a shared thread-safe token, disables conflicting controls, reacts to iOS memory warnings, restores UI state on every exit path, and cleans registered temporary files. Exporters receive the token and check it inside frame loops and writer back-pressure waits.

A shared `RenderSizePolicy` caps output dimensions while preserving aspect ratio. The cap is 3840 pixels on the long edge and 8,294,400 total pixels. This preserves up to UHD output while preventing portrait or unusual source sizes from creating oversized pixel-buffer pools.

### Depth preview

Depth preview returns a structured diagnostic payload containing requested/actual frame time, frame size, whether Vision saliency succeeded, whether person segmentation was used, and whether the deterministic fallback was used. Saliency failure no longer makes the button appear inert: the exporter falls back to a luminance/edge/vertical-prior map and still returns a usable preview. The UI shows an activity indicator, disables duplicate preview requests, validates decoded PNG data, and exposes a shareable diagnostics log.

### Add Effects integration

The category hook moves from `viewDidAppear` to `viewWillAppear`, then performs bounded run-loop retries until the category collection outlet and data source exist. This makes `Extensions & Scripts` present on the first visible frame while preserving the known-good proxy and translated index paths.

The recommendation carousel is hidden only through the known Objective-C outlets `recommendCollectionView` and `recommendCollectionViewHeightConst`. No heuristic traversal hides arbitrary collection views.

### BCC search metadata

Search metadata is normalized during IPA packaging rather than by mutating the signed app bundle at runtime. A repository script updates custom BCC XML metadata with canonical categories and aliases (`bcc`, `bbc`, `boris`, `borisfx`, title words and ID words). Unknown categories are remapped to supported Add Effects categories. The final IPA packaging step must run this script before rezipping.

## Error handling

- A second render request is rejected with a visible “render already running” message.
- Cancellation is cooperative and produces a distinct non-error status.
- Memory warnings request cancellation and report a memory-pressure message.
- Output files are deleted after successful Photos handoff, on cancellation, and on failure.
- Stale `AE-Motion-*` temporary files older than 24 hours are deleted at framework installation.
- Preview and render diagnostics include the concrete stage and underlying localized error.

## Testing

- Core tests cover dimension limiting, alias normalization and category normalization.
- A Python fixture test validates BCC XML rewriting against representative XML.
- All Swift files must parse under the local Swift compiler.
- Linux `swift test` must pass.
- GitHub Actions/Xcode remains the source of truth for UIKit/AVFoundation/Vision compilation.
- Device tests cover each render tool, cancellation, duplicate taps, memory-pressure recovery where practical, Depth preview and Add Effects first-frame appearance.

# AE Motion v2.0 Preset Platform Design

## Scope

v2.0 replaces the static preset recipe screen with a versioned XML preset platform. It also repairs the native Add Effects category keys used by Move/Transform and Distortion/Warp. It does not write into Alight Motion's private project database.

## Architecture

`AEMotionExtensionsCore` owns portable data and behavior:

- `PresetDocument` and typed parameter values
- XML encoding and decoding
- schema migration and validation
- macro evaluation and change comparison
- runtime compatibility checks
- atomic file storage and quarantine
- application adapters for Speed Remap, Easing, Camera Shake, and Color Palette
- native effect-category normalization

`AEMotionExtensionsHost` owns UIKit integration:

- preset library, search, sort, favorites, collections, recents, and usage counts
- typed preset editor, dependency editor, macro editor, and editable-template metadata
- import, export, duplication, rename, deletion, preview image, and validation display
- Preset Studio integration in four functional tools
- DaFont and Keyfla.me resource hub
- effect-category diagnostics in Safe Scan

## XML compatibility

The public schema version is `1.0`. Unknown vendor fields are kept in the `extensions` dictionary. Older supported schemas are migrated before validation. Newer schemas are rejected without modifying the file. Invalid user files are moved to Quarantine instead of being loaded into the active library.

## Macro behavior

Macros map an easy control to one or more advanced parameters. Numeric mappings use a declared input and output range. Curve scaling always starts from the parameter's `defaultValue`, preventing repeated slider movement from compounding errors. The current macro value is stored in the document extension namespace so Easy and Advanced views remain synchronized.

## Persistence

Built-in presets are refreshed atomically when the app version contains an updated definition. User presets live separately. Writes are atomic; invalid files are quarantined; duplicate imports receive a new user ID. Favorites, collections, recent usage, and usage counts are stored separately from portable XML.

## Add Effects categories

The target Alight Motion build uses the native XML keys:

- visible Move/Transform → `transform`
- visible Distortion/Warp → `distort`

The packaging normalizer keeps those keys and adds display/search aliases. It must run against the v1.9.1 Beta 10 effect set because Beta 11 already replaced the original Transform category metadata and cannot recover it from tags alone.

## Error handling

- malformed XML: reject or quarantine
- invalid parameter or dependency: show validation issues; disable Apply
- unsupported runtime target: keep preset editable and exportable; disable Apply
- missing optional dependency: warning
- missing required dependency: error
- failed tool adapter: show an alert without closing the library
- category integrity failure: abort IPA packaging

## Verification

- XML round-trip tests
- schema migration tests
- macro stability and reverse-value tests
- compatibility and validation tests
- file quarantine, duplicate, and built-in refresh tests
- real adapter tests
- native category and metadata-script idempotence tests
- Swift parse, Swift build, and GitHub Actions iOS framework build
- physical-device verification after packaging

## 1. 기술 결정

Alight Motion의 Add Effects 항목은 IPA의 `AlightMotion.app/BuiltinEffects/*.xml`에서 로드된다. 각 XML은 effect metadata, parameter schema, GLSL fragment shader 또는 multipass dependency를 포함한다.

따라서 v2.0.3은 다음 구조를 사용한다.

- Add Effects 신규 효과: AE Motion이 독립 작성한 XML + GLSL
- 효과 검사·상태·진단 UI: Swift framework
- 효과 병합·중복 제거·격리: Python packaging tools
- 독립 영상 처리 도구: 필요한 경우 Metal/Core Image
- Android APK: 기능 후보 분석 자료로만 사용
- APK의 XML, shader, `.ta`, texture, thumbnail, native library 직접 복사 금지

## 3. 현재 Phase 1 후보의 중복 판정

Beta 15 `BuiltinEffects`에는 다음 기능의 기존 구현이 이미 존재한다.

- Deep Glow
- Motion Blur·Directional Blur
- Camera Lens Blur
- Chromatic Aberration
- Light Sweep
- Dithering
- Frosted Blur
- Lens Distortion
- Manual Shake
- Halftone

위 기능은 동일 이름의 신규 효과를 추가하지 않는다. Auditor 결과가 정상이라면 유지하고, 비정상이면 동일 effect ID를 보존한 clean-room replacement로 교체한다.

현재 명확하게 누락된 1차 신규 기능:

1. Corner Pin
2. Adaptive Deband

후속 후보는 현재 효과의 기능 signature와 중복되지 않는 경우에만 추가한다.

## 5. 격리 방식

설치된 앱 bundle은 runtime에서 효과 파일을 수정하는 구조로 사용하지 않는다. 격리는 서명 전 packaging 단계에서 수행한다.

```text
AlightMotion.app/BuiltinEffects/<broken>.xml
→ AlightMotion.app/AEMotionQuarantine/BuiltinEffects/<broken>.xml
```

동시에 다음 파일을 생성한다.

```text
AlightMotion.app/AEMotionDiagnostics/effect-integrity.json
AlightMotion.app/AEMotionDiagnostics/quarantine-manifest.json
```

Swift framework는 위 report를 읽어 Diagnostics UI에 표시한다.

## 9. 오류 처리

- invalid descriptor는 load 대상으로 패키징하지 않음
- unresolved helper pass는 quarantine
- missing texture는 quarantine 또는 self-contained replacement
- duplicate ID는 build failure
- duplicate functional signature는 신규 추가 차단
- shader compile 실패는 effect 단위로 격리
- runtime diagnostics 실패는 원본 Alight Motion UI를 유지
- final render 실패 시 자동 품질 저하 금지
- 사용자 미디어·개인 경로를 report에 기록하지 않음

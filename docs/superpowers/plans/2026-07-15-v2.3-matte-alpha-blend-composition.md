# AE Motion v2.3 Matte·Alpha·Blend·Composition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one AE-like v2.3 composition release with editable multi-layer pre-compose, full blend groups, modern track mattes, parenting/nulls, channel/alpha tools, and real-time transactional preview.

**Architecture:** Add an immutable composition graph and transaction engine to `AEMotionExtensionsCore`. Add UIKit host adapters and contextual timeline UI to `AEMotionExtensionsHost`; provisional changes render from a shadow graph and commit only through verified host command paths.

**Tech Stack:** Swift 6, Swift Package Manager, UIKit, CoreGraphics/simd, XCTest, XcodeGen TestHost, Make, GitHub Actions.

## Global Constraints

- iOS deployment floor remains iOS 15.
- Preserve host main executable byte-for-byte.
- Preserve display name, icon, and bundle identifier `com.alightcreative.motion`.
- Exactly one source-built `AEMotionExtensionsHost.framework`.
- Unsigned IPA only.
- No private host timeline database writes.
- No APK/IPA code or asset copying and no encrypted-resource decryption.
- No render-and-reimport pre-compose fallback.
- Unsupported host contracts fail closed.

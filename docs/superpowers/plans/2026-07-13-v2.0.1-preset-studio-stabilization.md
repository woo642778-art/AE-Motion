# Preset Studio v2.0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore Preset Studio navigation and make Apply Preset target-aware, tool-aware, atomic, and predictable without changing other v2.0 features.

**Architecture:** Add a platform-independent target resolver in the core module and a UIKit application context that routes a selected preset back to the tool that opened the library. Preserve standalone use by explicitly resolving supported targets and opening the selected compatible tool.

**Tech Stack:** Swift 6, UIKit, Swift Package Manager, XCTest.

## Global Constraints

- Minimum iOS remains 15.0.
- Do not modify Alight Motion private project or timeline data.
- Do not change Add Effects metadata, rendering, Resource Hub, import/export, favorites, tags, or other working v2.0 behavior.
- The final IPA remains unsigned.

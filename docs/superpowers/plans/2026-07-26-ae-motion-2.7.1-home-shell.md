# AE Motion 2.7.1 Home Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a source-controlled AE Motion 2.7.1 Home, Projects, and Templates shell with premium native motion while preserving every compiled 2.7 feature through a legacy-wrapper packaging boundary.

**Architecture:** The existing 2.7 `AEMotionExtensionsHost` binary is renamed to `AEMotionExtensionsLegacy` and loaded first by a new framework at the original app load path. The new framework owns only the 2.7.1 product shell, motion components, version metadata, and allowlisted runtime hooks. A pure Swift state reducer is the single source of truth for selected root tab and root-navigation visibility.

**Tech Stack:** Swift 6, Swift Package Manager, UIKit, Core Animation, Objective-C runtime, Darwin `dlopen`, Python source-contract and packaging tests, GitHub Actions macOS Xcode build.

## Global Constraints

- Product release version: `2.7.1`.
- First release build number: `839`; subsequent build attempts increment the build number without changing the marketing version unless user-visible behavior changes.
- iOS deployment floor remains iOS 15.
- Existing compiled 2.7 functionality must load before 2.7.1 hooks install.
- Home, Projects, and Templates must not independently install global bottom navigation.
- Detail, editor, template-preview, and tool destinations must hide root bottom navigation.
- No React, Tailwind, DOM, hover, cursor, or WebView implementation in the native shell.
- No new third-party dependency in 2.7.1. Rive remains a future optional dependency after license, binary-size, and performance review.
- No fake project, template, analytics, render, or storage data.
- Reduce Motion and Reduce Transparency must receive explicit fallbacks.
- The branch must not be merged into `main` without user approval.

# AE motion v2.2 Beta 20 Full Effect Restoration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one source-built AE motion v2.2 Beta 20 release with all 700 baseline effect IDs active in their original categories, a working Other category, a crash-isolated Extensions & Scripts hub, zero packaged quarantine entries, and recorded iPhone/iPad qualification for all 130 restored effects.

**Architecture:** Reconstruct the canonical 700-effect baseline from the v2.1 Beta 17 IPA by combining active and quarantined descriptors, then drive every repair from immutable manifests keyed by effect ID and descriptor SHA-256. Replace quarantine-at-package-time with a repair queue that must be empty before final packaging. Build one `AEMotionExtensionsHost.framework` from source, produce a device-test candidate first, ingest exact-hash device evidence, and only then permit the final unsigned Beta 20 IPA.

**Tech Stack:** Swift 6, Swift Package Manager, UIKit, Objective-C runtime, Python 3.12, XML/GLSL descriptor tooling, GitHub Actions on macOS 15 and Ubuntu, Xcode generic iOS arm64 Release build, ZIP/IPA packaging, SHA-256 manifests.

## Global Constraints

- Deployment floor remains iOS 15 and macOS 13 as declared in `Package.swift`.
- The main app executable SHA-256 must remain `21576328f5bd3a28ecce882b855159d354610add5415c54a6187c83879b577fe`.
- The final baseline and packaged effect ID sets must each contain exactly 700 unique IDs.
- The final distributable IPA must contain zero effect descriptors under `AEMotionQuarantine`.
- Every repaired effect must preserve its original effect ID and return to its earliest valid original category.
- An effect belongs to Other only when the canonical baseline category is exactly `other` after normalization.
- No count target may move a non-Other effect into Other.
- No proprietary implementation code may be copied from unrelated APK, IPA, plugin, encrypted project, or private database.
- No code may write directly to Alight Motion's private project or timeline database.
- Beta 19's binary-patched two-framework loader must not appear in Beta 20.
- The final app must contain exactly one non-system extension framework: `AEMotionExtensionsHost.framework`.
- A failed or missing effect blocks final packaging; final packaging may not silently omit it.
- Static analysis must never be recorded as a physical-device pass.
- Final release evidence requires at least one iPhone-class and one iPad-class device.
- The unsigned final IPA must contain no `_CodeSignature`, `CodeResources`, or `embedded.mobileprovision` entries.
- Existing open pull requests must not be merged automatically.

DEFAULT_STEP_BY_TYPE = {"integer": "1", "slider": "0.01", "spinner": "0.01"}

def normalize_numeric_control(element: ET.Element) -> None:
    minimum = Decimal(element.attrib.get("min", "0"))
    maximum = Decimal(element.attrib.get("max", "1"))
    if minimum > maximum:
        minimum, maximum = maximum, minimum
    default = min(max(Decimal(element.attrib.get("default", str(minimum))), minimum), maximum)

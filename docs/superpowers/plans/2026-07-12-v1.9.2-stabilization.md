# AE Motion Extensions v1.9.2 Stabilization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Complete the v1.9.2 stability scope: dependable Depth preview, BCC search metadata, immediate Extensions insertion, recommendation-carousel removal, and safe cancellable rendering.

**Architecture:** Pure normalization and render-size policy live in `AEMotionExtensionsCore`; UIKit/AVFoundation coordination lives in focused host files. Existing exporters remain synchronous but gain cooperative cancellation and shared dimension limiting. Add Effects changes retain the proven category proxy and only alter lifecycle timing plus known-outlet hiding.

**Tech Stack:** Swift 6, UIKit, AVFoundation, Vision, Core Image, Photos, Objective-C runtime, Python 3 for IPA resource normalization.

## Global Constraints

- Minimum deployment target remains iOS 15.0.
- Do not add third-party frameworks or model files.
- Do not mutate the signed app bundle at runtime.
- Preserve the known-good translated-index-path category proxy.
- Do not call private Alight Motion layer-insertion methods.
- Output dimension cap: long edge 3840 pixels and total area 8,294,400 pixels.
- Stale temporary file lifetime: 24 hours.

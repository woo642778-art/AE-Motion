# AE motion v2.2 Beta 19 Device Checklist

## Installation

- [ ] Recursively sign the app executable and every embedded framework.
- [ ] Install the same signed build on one supported iPhone and one supported iPad.
- [ ] Confirm the display name is `AE motion` and the bundle identifier remains `com.alightcreative.motion`.

## Contextual controls

- [ ] Open a Transform panel and confirm only the Motion contextual button appears beside compatible controls.
- [ ] Open a keyframe or graph panel and confirm only the Graph contextual button appears beside compatible controls.
- [ ] Open a Speed panel and confirm only the Velocity contextual button appears beside compatible controls.
- [ ] Open an Effect parameter panel and confirm only the Live contextual button appears beside compatible controls.
- [ ] Confirm unsupported panels receive no contextual editing button.
- [ ] Confirm Extensions & Scripts does not contain Animation Core or other editing-only shortcuts.

## Live preview and rollback

- [ ] Move every contextual slider and confirm the current preview changes before finger release.
- [ ] Use Transform drag controls and confirm the current preview follows the gesture continuously.
- [ ] Tap Cancel and confirm the original host values and preview are restored.
- [ ] Dismiss the sheet interactively without Done and confirm rollback.
- [ ] Change the selected layer or clip during an active edit and confirm rollback.
- [ ] Confirm no export, Photos handoff, file replacement, or reimport step is required.

## BCC Edge Glow

- [ ] Confirm the BCC Edge Glow thumbnail is visible in Add Effects.
- [ ] Confirm the thumbnail is not blank, stretched, or replaced by a generic placeholder.
- [ ] Add and remove BCC Edge Glow ten consecutive times without a crash.
- [ ] Change representative parameters and confirm immediate preview updates.
- [ ] Save, close, and reopen the project.
- [ ] Render one short portrait clip and one short landscape clip.

## Visual effect qualification

- [ ] Test the transparent checkerboard fixture.
- [ ] Test the full-frame color bars fixture.
- [ ] Test portrait and landscape fixtures.
- [ ] Test an alpha-edge subject.
- [ ] Record unexpected black bars, blank output, invalid alpha, cropping, timeouts, and crashes as failures.
- [ ] Restore the prior project state after each candidate effect.

## Qualification record export

Every tested descriptor requires a record containing:

- `effectID`
- exact lowercase `descriptorSHA256`
- `hostVersion`
- `deviceClass`
- `stage: device`
- `disposition`: `passed`, `failed`, `timeout`, or `crashed`
- visual metrics for black borders, transparency, and alpha loss
- optional reference screenshot hash

Only records with `stage: device`, `disposition: passed`, and the exact current descriptor SHA-256 may qualify an effect for the Other category.

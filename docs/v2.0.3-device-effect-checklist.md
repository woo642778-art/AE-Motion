## Beta 15 regression sequence

1. Enter Add Effects 20 times.
2. Open Move/Transform.
3. Open Distortion/Warp.
4. Search for BCC, BBC, BorisFX and Continuum.
5. Open Extensions & Scripts.
6. Open Effect Integrity.
7. Apply and remove ten known-good native effects.
8. Render and save one result.
9. Background and foreground the app.
10. Repeat after relaunch.

Record the device model, OS version, exact IPA SHA-256 and any `.ips` crash log. v2.0.3a is complete only after the Xcode iOS Release build, static IPA checks and this regression sequence pass.

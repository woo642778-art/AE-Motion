# AE motion v2.1 Beta 17 Static Verification

The verified source revision is `57a665e696efcfa5cee0ad87ac081862e1552b31` on `feature/v2.1-project-reliability`. GitHub Actions run `29332197579` completed successfully on macOS 15 using Xcode 16.4. The run completed 51 Swift tests with zero failures, including 10 Project Reliability tests, and also passed the effect metadata tests, effect integrity tests, Other category restoration tests, Swift 6 isolation contracts, native UI contract, source parsing, and the generic arm64 iOS Release framework build.

The Add Effects Other-tab defect was traced to packaged metadata rather than the collection UI. The previous package contained zero descriptors with `category="other"`, and the metadata normalizer did not preserve the Other category. Beta 17 preserves `other` as a supported native category and restores 11 safe, pre-existing effect descriptors from Procedural to Other. Verification confirmed that their effect IDs and all XML content after the opening effect tag, including shader bodies, remained byte-identical. No quarantined descriptor was restored.

The final package contains 586 effect descriptors. The category counts are Drawing 41, Distort 99, Color 105, Procedural 140, Transform 38, 3D 39, Text 7, Blur 60, Opacity 11, Matte 28, Other 11, and Repeat 7. The final effect integrity report classifies all 586 packaged descriptors as visible existing-working effects, with zero unsafe descriptors remaining.
